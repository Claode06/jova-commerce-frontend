# Phase 15 — Human UAT Scenarios

## 1. Accent Visibility — Homepage
1. Open homepage
2. Scroll to "Produk Terbaru" section
3. Hover over "Lihat Semua" link — should turn amber gold
4. Check rating stars on product cards — should be amber gold

## 2. Accent Visibility — Product Listing
1. Go to `/products`
2. Click a category filter — chip should appear with amber background
3. Click a pagination number — active page should be amber
4. Change sort dropdown — focus border should be amber

## 3. Accent Visibility — Product Detail
1. Open any product
2. Click a variant pill — selected should be amber
3. Click "Deskripsi/Fitur/Ulasan" tabs — active underline should be amber
4. Check star rating text — should be amber

## 4. Accent Visibility — Orders
1. Go to `/orders` (if logged in)
2. Click tabs (Semua/Menunggu/Diproses) — active underline should be amber

## 5. Accent Visibility — Forms
1. Open login page
2. Click any input field — focus border should be amber gold
3. Repeat for register, checkout, profile pages

## 6. Accent Visibility — Footer
1. Scroll to footer
2. Hover over Instagram/TikTok/WhatsApp icons — border should turn amber gold

## 7. Accent Visibility — Payment
1. Start payment flow
2. Select a bank account — border should be amber
3. Hover over upload area — border should be amber

## 8. Status Badges
1. View orders with different statuses
2. Each status badge should have a background tint (not just text)
