## Manual Testing Scenarios

### TC-01: Profile Form Styling
1. Login, go to /profile
2. **Expected:** Form inputs styled same as login page — consistent borders, padding, icons
3. Update profile
4. **Expected:** Works correctly

### TC-02: Payment Page Styling
1. Login, create order via checkout
2. Go to /payment/{orderId}
3. **Expected:** All elements use Stella monochrome black/white theme (no blue/primary colored buttons or alerts)

### TC-03: Language Consistency
1. Go to /login
2. **Expected:** All text in Bahasa Indonesia (not mixed English/Indonesian)
3. Go to /register
4. **Expected:** Same — consistent Indonesian language
